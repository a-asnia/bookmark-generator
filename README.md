# Bookmark Forge

Генератор плоских 3D-печатных закладок из линейных рисунков. Работает целиком в браузере, без сервера.

**Приложение:** https://a-asnia.github.io/bookmark-generator/

## Что умеет

- **В рамке** — ажурная закладка: линии рисунка становятся пластиком, промежутки — дырками. Формы рамки: прямоугольник, скруглённый, квадрат, круг, овал, арка, шестиугольник, угол (на дверной косяк). Картинку можно обрезать по рамке или оставить торчащей.
- **С держателем** — картинка садится «шапкой» на клипсу или пластину и заходит на неё на несколько миллиметров. 11 держателей нарисованы заново по мотивам общедоступных шаблонов (3 клипсы с язычком, клипса-рамка, 7 пластин). Шапка может быть толще основы.
- **Без рамки** — просто плоская фигура по контуру рисунка.
- **Стили:** ажур, силуэт, рельеф (силуэт + линии сверху вторым цветом).
- **Подставка** — брусок с пазом, чтобы закладка стояла как стенд.
- **Правка:** залить дырку, удалить кусок, утолщить или стереть кистью, сдвинуть точку, скруглить угол. Глобальное утолщение, сглаживание, инверсия, удаление мусора и висящих кусков.
- **Экспорт:** 3MF для Bambu Studio / Orca (детали разложены по слотам филамента, профиль принтера A1 mini по умолчанию), обычный 3MF для PrusaSlicer / Cura, STL в zip.

## Вход

PNG, JPG, WebP, GIF, SVG. Лучше всего — линейный рисунок на прозрачном фоне; для белого фона есть порог яркости.

## Как устроено

```
картинка → маска (порог/альфа, кисти, заливка) → утолщение → трассировка контуров
        → упрощение → правки точек → размещение в мм → булевы операции с рамкой/держателем
        → экструзия → 3MF / STL
```

- `src/geom` — растровые операции, трассировка маски в контуры, булева геометрия (polygon-clipping), формы рамок и держателей, экструзия.
- `src/model` — состояние проекта и конвейер сборки деталей.
- `src/export` — писатели 3MF (Bambu и generic) и STL.
- `src/ui` — React-интерфейс: 2D-редактор на SVG и 3D-превью на three.js.

## Разработка

```
npm install
npm run dev
npm run build
```

Деплой на GitHub Pages идёт автоматически: при пуше в `main` workflow собирает сайт и кладёт его в ветку `gh-pages` (Settings → Pages → Source: Deploy from a branch, `gh-pages`).
